Leap Gymnastics vector logo package

Files included:
- .ai: PDF-compatible Illustrator vector file for Windows/Adobe Illustrator.
- .eps: Standard vector file accepted by most print shops.
- .svg: Web/editor vector file.
- .pdf: Vector PDF with transparent background.
- *_transparent.png: Transparent PNG export.
- *_preview.png: Preview on contrasting background for easy viewing.

Use the WHITE vector version for dark shirts and the BLACK vector version for light shirts.
The white vector files may look blank in Windows preview or on a white artboard because the logo is white on transparent.
No black background is included in the vector print files.
These were generated as vector traces from the clean uploaded logo image, not from an original native Adobe Illustrator source file.
